# DermaXplain

DermaXplain is an MSc in Computing (Artificial Intelligence) practicum project at Dublin City University, completed in 2026.

The project evaluates post-hoc explainable AI (XAI) methods for skin-lesion classification by comparing Grad-CAM, SHAP, and LIME saliency maps with lesion masks and ABCD-inspired pseudo-concept maps representing asymmetry, border irregularity, and colour heterogeneity.

6. `03_create_pilot_subset_stratified_representative_1260.ipynb`

## Data Availability
The project uses the HAM10000 and ISIC 2018 dermoscopic datasets. Original dataset images can be obtained from their official sources.  
A temporary Google Drive folder contains the datasets used in this project. The first notebook `src/00_download_datasets_from_gdrive.ipynb` downloads the datasets directly from this folder.

## Environment
All code was produced in an Ubuntu 22.04 LTS environment with Python 3.12.3. Environment setup details can be found in `docs/documentation/DermaXplain_environment_setup.txt`.

Packages used include `PyTorch`, `torchvision`, `scikit-learn`, `pandas`, `numpy`, `matplotlib`, `seaborn`, `shap`, `lime`, and `opencv-python`.
