# DermaXplain

DermaXplain is an MSc in Computing (Artificial Intelligence) practicum project at Dublin City University, completed in 2026.

The project evaluates post-hoc explainable AI methods for skin-lesion classification by comparing Grad-CAM, SHAP, and LIME saliency maps with lesion masks and ABCD-inspired pseudo-concept maps representing asymmetry, border irregularity, and colour heterogeneity.

## Data availability
The project uses the HAM10000 and ISIC 2018 dermoscopic datasets. Original dataset images can be obtained from their official sources.
A temporary Google Drive folder contains the datasets used in this project. The first notebook `00_download_datasets_from_gdrive.ipynb` downloads the datasets from this folder.

## Environment
All code was produced from a Ubutu 22.04 LTS environment with Python 3.12.3. Environment setup is described in docs/documentation/DermaXplain_environment_setup.txt
Packages used include PyTorch, torchvision, scikit-learn, pandas, numpy, matplotlib, seaborn, shap, lime, and opencv-python. A requirements file is provided in `src/requirements.txt` for easy environment setup.
and for running in a renku environment, requirements_renku.txt is provided in `src/requirements_renku.txt` for easy environment setup.
